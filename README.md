# Milk It — Test Flight 0.1
A mobile-first social investigation prototype.

This is the **whole-product tester**, not just the Evidence Room.

## Testable flow
- Browse a seeded social feed
- Like / Promote / Share
- Tap **Milk It** to open the investigation trail
- Add findings, questions, sources, and connections
- Spotlight useful contributions
- Confirm narrow factual contributions
- Create a new investigation
- Enter the separate interactive Evidence Room
- Drag evidence while red-string connections follow it
- See the beginnings of investigator reputation

Core loop: **POST → MILK → CONTRIBUTE → CONNECT → CREDIT**

Everything is front-end demo behavior for concept testing; no production database/auth yet.
